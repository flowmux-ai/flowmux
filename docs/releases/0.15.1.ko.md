# Flowmux 0.15.1

[English release notes](https://github.com/flowmux-ai/flowmux/blob/v0.15.1/docs/releases/0.15.1.md)

## 수정 사항

- 창을 닫을 때 **Stop agents**를 선택하면 해당 창의 탭에 연결된 에이전트만
  종료합니다. 다른 창이나 Background의 에이전트는 계속 실행됩니다. 확인창이
  열린 사이 다른 창으로 옮긴 에이전트도 계속 실행됩니다.
- 에디터 탭에서 마지막 문서를 닫으면 탭도 함께 닫힙니다. 이전 세션에서 복원된
  빈 에디터 탭은 같은 작업공간 경로의 파일을 열 때 다시 사용할 수 있습니다.
  미저장 변경 사항이 있으면 저장·버리기·취소를 선택할 수 있습니다.
- 터미널에서 텍스트를 드래그하는 중에 출력이 갱신되어도 선택 영역이 유지됩니다.
  포인터가 화면 가장자리에 닿아 자동으로 스크롤되는 동안에도 적용됩니다.

## 0.15.0에서 업데이트할 때

Linux용 Agent Host 프로토콜이 18에서 19로 바뀌었습니다. 0.15.0에서 이미 실행
중인 에이전트와 셸은 계속 동작합니다. 해당 탭에 다시 연결하려면 실행을 시작한
빌드를 사용하세요. [에이전트 세션 안내](https://github.com/flowmux-ai/flowmux/blob/v0.15.1/docs/agent-sessions.md)

## 다운로드

Linux x86_64용 Debian 패키지와 tarball을 제공합니다. Apple Silicon용 macOS
프리뷰는 임시 서명한 DMG로 배포하며, `/opt/homebrew`에 설치된 Homebrew
`gtk4`, `libadwaita`, `vte3`가 필요합니다. 각 파일의 SHA-256 체크섬도 제공합니다.
