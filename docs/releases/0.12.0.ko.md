# Flowmux 0.12.0 — 웹 작업을 같은 화면에서 실행하고 확인하세요

이번 업데이트는 **브라우저에서 실제로 일을 끝내는 과정**에 집중했습니다. 에이전트가 터미널 옆에서 폼을 입력하고 검증하며, 파일을 올리고 내려받고, 캔버스를 조작하고 결과 화면을 저장할 수 있습니다. 사용자는 같은 탭에서 현재 단계와 결과를 확인하고 필요할 때 직접 제어권을 가져올 수 있습니다.

[다운로드 및 영문 릴리즈](https://github.com/flowmux-ai/flowmux/releases/tag/v0.12.0) · [0.11.4 이후 전체 변경](https://github.com/flowmux-ai/flowmux/compare/v0.11.4...v0.12.0)

동일한 창 크기와 기본 테마로 실행한 macOS 실제 화면입니다. 이미지를 누르면 원본 크기로 볼 수 있습니다. 익숙한 pane·탭 배치는 그대로 이어집니다.

## 브라우저로 이런 작업을 할 수 있습니다

### 1. 폼 입력 → 항목별 검증 → 페이지 결과 확인

에이전트에게 이렇게 요청해 보세요.

> 프로젝트 이름, 검토자 이메일, 릴리즈 트랙을 입력해 줘. 세 항목을 검증하고,
> 요약을 만든 뒤 ‘Ready to review’가 나타나는지 확인해 줘.

![터미널의 세 항목 검증 결과와 브라우저의 Form checked, Result confirmed 카드](https://raw.githubusercontent.com/flowmux-ai/flowmux/v0.12.0/docs/releases/0.12.0/browser-form.jpg)

`form`은 여러 필드를 처리한 후 각각의 검증 결과를 반환합니다. **폼 입력만으로 제출 명령을 보내지는 않습니다.** 별도의 클릭에 기대 결과를 지정하면 입력 전달과 페이지 결과 확인을 구분할 수 있습니다. 위 예시는 실제로 세 항목을 검증한 뒤 요약 문구가 나타나는 것까지 확인했습니다.

작업 표시줄에서는 이름과 현재 단계를 볼 수 있고, **Take control / Continue / Stop**으로 에이전트와 제어를 주고받을 수 있습니다. **Results**에는 폼 검증, 파일, 캡처와 동작 결과가 표시됩니다. 결과가 늦게 보인다는 이유로 같은 동작을 자동 재전송하지 않습니다.

### 2. 파일 업로드 → 다운로드 완료 확인 → 캔버스 조작

> 샘플 CSV를 선택해서 세 행이 읽혔는지 확인해 줘. 체크리스트를 내려받고,
> 캔버스에 경로를 그린 다음 완성된 페이지를 저장해 줘.

![CSV 선택과 다운로드 완료, 네이티브 드래그로 그린 경로가 보이는 실제 브라우저 화면](https://raw.githubusercontent.com/flowmux-ai/flowmux/v0.12.0/docs/releases/0.12.0/browser-files-canvas.jpg)

실제 파일 선택 창으로 CSV를 지정하고, 다운로드가 `complete`에 도달한 뒤 원본과 파일 내용이 같은지 비교했습니다. 캔버스 경로는 세 번의 네이티브 드래그로 그렸습니다. [전체 문서 캡처](https://raw.githubusercontent.com/flowmux-ai/flowmux/v0.12.0/docs/releases/0.12.0/demo-full-page.png)에는 폼부터 파일과 캔버스까지 담겨 있습니다. 화면을 직접 스크롤하며 이어 붙이지 않아도 됩니다.

예시에 사용한 사이트는 [로컬 데모 페이지](https://github.com/flowmux-ai/flowmux/blob/v0.12.0/docs/releases/0.12.0/demo.html)입니다. 가상의 프로젝트·연락처를 사용하고 외부 서비스로 전송하지 않습니다. Flowmux 화면과 처리 결과는 실제 실행을 촬영한 것이며 UI 목업이 아닙니다.

### 그 밖에 지원하는 브라우저 작업

| 하고 싶은 일 | 사용할 수 있는 기능 |
| --- | --- |
| 사이트·편집기 조작 | 네이티브 텍스트 입력, 키, 클릭·더블클릭·hover, 좌표 입력과 드래그 |
| 필요한 요소 찾기 | 역할·이름·레이블·텍스트 검색, 범위를 좁힌 compact snapshot, 열린 Shadow DOM과 동일 출처 iframe 탐색 |
| 탭을 오가지 않고 정확히 제어 | 탭 surface 고정, 네이티브 팝업을 새 탭으로 유지, 오래된 요소 참조 거부 |
| 확인창·파일 처리 | 페이지 alert·confirm·prompt 응답, 허용 디렉터리 안에서 업로드 파일 선택, 다운로드 목록·경로·취소·완료 확인 |
| 결과 공유 | 보이는 화면·전체 문서·특정 요소를 PNG로 저장, `ffmpeg`/`libx264`로 무음 MP4 화면 샘플 녹화 |
| 미디어 검토 | 재생·일시정지·구간 이동·음소거와 실제 재생 상태 확인 |
| 막힌 이유 파악 | 런타임 진단, 조건 대기, 동작 결과 영수증으로 입력 전달·확인 대기·결과 확인을 구분 |

페이지 전체 캡처와 짧은 녹화는 다음처럼 요청할 수 있습니다. `$PANE`에는 실제 브라우저 pane ID를 사용합니다.

```sh
flowmux browser screenshot "$PANE" /tmp/page.png --full-page
flowmux browser record "$PANE" /tmp/walkthrough.mp4 --seconds 5 --fps 5
```

[브라우저 작업 가이드](https://github.com/flowmux-ai/flowmux/blob/v0.12.0/docs/browser-workflow.md)와 [CLI 스킬](https://github.com/flowmux-ai/flowmux/blob/v0.12.0/.agents/skills/flowmux-browser/SKILL.md)에 탭·작업 소유권과 상세 사용법이 정리되어 있습니다.

| Installed 표시, 공통 새로고침으로 재확인 | **Up to date**와 확인 기준 앱 버전 표시, 버튼을 눌러 직접 재확인 |

- 새 앱 버전의 첫 실행에서 **이미 설치된** Flowmux CLI·Team 스킬만 자동 갱신합니다.
- 수정한 파일은 백업하고, 삭제했거나 설치하지 않은 스킬은 새로 만들지 않습니다.
- 알려진 사용자 영역의 기존·공유 복사본도 갱신합니다. 프로젝트 스킬과 에이전트 훅·설정은 바꾸지 않습니다.
- 갱신에 성공하면 같은 버전을 실행할 때마다 반복해서 덮어쓰지 않습니다.
- Gemini 지원, CLI·Team별 설치, 설치 경로·중복 복사본 안내, **Check Team setup**도 추가했습니다.

최신 표시는 **실행 중인 앱에 포함된 스킬과 일치한다는 의미**입니다. 에이전트가 새 내용을 사용하려면 스킬을 다시 읽거나 새 세션을 시작해야 할 수 있습니다.

## 일상적인 작업에서도 달라지는 점

- **세션 재개:** 저장한 세션에서 에이전트를 선택하고 명시적으로 YOLO 재개 옵션을 사용할 수 있습니다. macOS에서는 로그인 셸 PATH를 보존합니다.
- **Team 작업:** Claude Code·Codex 외에 Gemini CLI·Antigravity CLI도 리더로 사용할 수 있습니다. 워커는 Claude Code·Codex를 사용합니다. 유휴 워커 재사용, 관측된 사용량 제한에 따른 라우팅, 복구·쿼터·시간 제한 처리를 개선했습니다. YOLO 워커는 선택 옵션입니다.
- **사용량 표시:** 막대를 50% 넓혔고 고정한 제한과 Claude 모델별 제한을 구분해 보여줍니다.
- **터미널:** 가려진 뷰포트의 텍스트 보존, 제목 갱신 제한, 긴 파일 경로 인식을 개선했습니다.
- **macOS:** 실행 중인 세션과 앱 경로를 보존하는 설치, 브라우저 파일 선택 창의 포커스, 별도 검사기 창과 탭 드래그 미리보기를 다듬었습니다.
- **의존성:** 이번 개발 주기에 확인한 Tokio 보안 권고에 대응하는 업데이트를 포함합니다.

## 설치와 지원 범위

[릴리즈 Assets](https://github.com/flowmux-ai/flowmux/releases/tag/v0.12.0)에서 Linux x86_64 `.deb`·tarball 또는 Apple Silicon `.dmg`를 내려받을 수 있습니다. 각 파일에는 SHA-256 검증 파일이 함께 제공됩니다. 지원되는 로컬 설치는 앱 내 업데이트를 사용할 수 있고, 패키지 설치는 배포 경로에 맞는 안내를 따릅니다.

- **macOS 프리뷰:** Homebrew의 `gtk4`, `libadwaita`, `vte3`가 `/opt/homebrew`에 필요합니다. DMG 안의 앱을 Applications로 옮겨 설치합니다. 독립 실행 패키지나 Intel Mac 패키지가 아니며, Developer ID 서명·공증이 없어 Gatekeeper가 차단할 수 있습니다.
- **Linux 입력:** X11은 네이티브 입력을 사용합니다. Wayland는 호환 RemoteDesktop 포털과 사용자의 데스크톱 제어 동의가 필요하며, 대상 창에 포커스를 유지해야 합니다.
- **캡처·미디어:** macOS 전체 문서 캡처는 macOS 15 이상과 64 MiB 비트맵 제한이 적용됩니다. 동영상·WebGL 레이어가 문서 캡처에서 빠질 수 있습니다. 녹화는 무음 프레임 샘플링이며, 미디어 재생은 설치된 코덱에 영향을 받습니다.
- **경계:** 다른 출처의 iframe과 닫힌 Shadow DOM, CDP 네트워크 모킹·기기 에뮬레이션, 외부 브라우저 쿠키 가져오기는 지원하지 않습니다. 화면의 결과 확인만으로 서버 저장까지 입증되는 것은 아닙니다.
