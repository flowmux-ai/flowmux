# Flowmux 0.14.1

Flowmux 0.14.1은 메모리 정보 노출 권고에 대응해 내장 SQLite를 갱신하고,
백그라운드 워크스페이스 자동화가 사용 중인 워크스페이스를 방해하지 않도록
개선합니다. 이 문서는 v0.14.0 이후 변경 사항을 설명합니다.

[English release notes](https://github.com/flowmux-ai/flowmux/blob/v0.14.1/docs/releases/0.14.1.md)

## SQLite 보안 업데이트

- `rusqlite`를 0.41.1, `libsqlite3-sys`를 0.39.1로 올려 내장 SQLite를
  3.46.0에서 **3.54.1**로 갱신했습니다.
- [RUSTSEC-2026-0459 / CVE-2026-119375](https://rustsec.org/advisories/RUSTSEC-2026-0459.html)에
  대응합니다. SQLite 3.54.0 이전 버전은 페이지 크기가 서로 다른 변조된 DB와
  인접 WAL 파일을 함께 열 때 초기화되지 않은 페이지 캐시 메모리를 쿼리 결과에
  포함할 수 있습니다. 공격자가 제어하는 로컬 파일을 열어야 하는 조건이며,
  Flowmux에서 실제로 악용 가능한지는 확인되지 않았습니다.
- 쿠키 가져오기, 외부 에이전트 세션 기록, Session Flow, 리뷰 초안 저장에
  사용하는 SQLite를 갱신합니다. Flowmux DB 스키마는 변경하지 않습니다.
  WAL의 세션 기록을 읽고 원본 DB와 WAL을 보존하는 회귀 테스트를 추가했습니다.

## 백그라운드 작업과 에이전트 팀

- `workspace new --background`로 현재 화면을 바꾸지 않고 워크스페이스를 만듭니다.
- 백그라운드 워크스페이스의 pane·tab 명령이 현재 화면과 키보드 포커스를
  유지합니다. 새 탭은 `focus-pane`으로 기억한 pane에 열립니다.
- Team 워크스페이스도 현재 에이전트가 기본으로 작업합니다. 독립적으로 처리할
  가치가 있는 작업이나 명시적인 요청에 한해 위임하며, 작업 자체의 실패는
  자동으로 반복 실행하지 않고 보고합니다.
- 설치된 스킬, 공통 GUI 상태, 워크스페이스 포커스·확대, macOS 에이전트 저장
  경로 복원에 대한 회귀 테스트 환경을 보완했습니다.
- 동작 줄이기 설정으로 즉시 닫힌 경우를 포함해, 이미 닫힌 프로세스 종료
  알림 창을 다시 닫으면서 오류가 발생하는 문제를 수정했습니다.

## 업데이트와 다운로드

- 앱과 CLI를 함께 업데이트한 뒤 편한 시점에 Flowmux를 다시 시작해야 수정된
  SQLite가 적용됩니다. 기존 창은 이전 빌드로 계속 실행됩니다.
- Linux x86_64는 tarball·Debian 패키지, macOS Apple Silicon은 DMG를 제공합니다.
  각 바이너리 다운로드에는 `.sha256` 파일이 포함됩니다.
- macOS 프리뷰는 `/opt/homebrew`의 Homebrew 런타임 라이브러리가 필요합니다.
  ad-hoc 서명이며 Developer ID 서명·공증은 제공하지 않습니다. Intel macOS
  바이너리는 제공하지 않습니다.
