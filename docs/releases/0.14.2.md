# Flowmux 0.14.2

Flowmux 0.14.2 improves browser automation, page reading, and tab-close safety.
These notes cover changes since v0.14.1.

[한국어 릴리스 노트](https://github.com/flowmux-ai/flowmux/blob/v0.14.2/docs/releases/0.14.2.ko.md)

## Browser automation and reading

- Add dense model-facing snapshots and read-only `read`, `links`, `grep`,
  `query`, and `options` commands. Link and selector queries reach frames and
  shadow roots; sensitive card and passcode values are redacted in dense snapshots.
- Run up to 20 browser commands in one bounded batch with `browser run`.
  Preserve completed results when a later step receives no response, and stop
  when navigation, a dialog, or another condition requires a fresh observation.
- Scroll by viewport pages, including within an inner scrolling area, and read
  `eval` scripts from standard input.
- Wait for the replacement document during navigation and report failed loads
  more clearly, including pages that remain blank.
- Improve covered-click diagnostics, modal handling, form reference resolution,
  and native input completion when a page replaces its document.
- Resolve the calling Codex session before opening a browser, with explicit
  `--pane` selection when needed. Ambiguous bindings fail instead of selecting
  another session's pane.
- Index selector uniqueness once per snapshot root to reduce repeated work.

## Tab closing and GTK runtime guidance

- Make Alt+W use the tab-close confirmation flow.
- Include a GTK 4.14.5 icon-cache lifetime patch, regression checks, and deployment
  instructions. This patch must be applied to the GTK runtime separately;
  upgrading Flowmux alone does not activate it.

## Downloads

- Linux x86_64: tarball and Debian package. macOS Apple Silicon: DMG.
  Each binary download includes a `.sha256` file.
- The macOS preview requires Homebrew runtime libraries under `/opt/homebrew`.
  It is ad-hoc signed, not Developer ID signed or notarized. Intel macOS binaries
  are not provided.
