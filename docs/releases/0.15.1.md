# Flowmux 0.15.1

[한국어 릴리스 노트](https://github.com/flowmux-ai/flowmux/blob/v0.15.1/docs/releases/0.15.1.ko.md)

## Fixes

- When closing a window, **Stop agents** stops only the agents attached to
  that window. Agents in other windows and in Background keep running,
  including an agent moved to another window while the confirmation was open.
- Closing the last document in an editor tab closes the tab too. If a
  previous session restores an empty editor tab, opening a file from the same
  workspace root can reuse it. Unsaved changes still prompt you to save,
  discard, or cancel.
- Terminal text selections stay in place when output refreshes during a drag,
  including while the terminal scrolls with the pointer at the edge.

## Upgrading from 0.15.0

On Linux, the Agent Host protocol changes from 18 to 19. Agents and shells
already running under 0.15.0 keep running. Use the build that started them
to reconnect to those live tabs. [Agent sessions guide](https://github.com/flowmux-ai/flowmux/blob/v0.15.1/docs/agent-sessions.md)

## Downloads

Linux x86_64 packages are available as a Debian package and a tarball.
The Apple Silicon macOS preview comes as an ad-hoc signed DMG and requires
Homebrew `gtk4`, `libadwaita`, and `vte3` under `/opt/homebrew`.
Each download has a matching SHA-256 checksum.
