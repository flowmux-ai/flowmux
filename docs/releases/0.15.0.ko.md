# Flowmux 0.15.0

Flowmux 0.15.0은 Linux에 Agent Host를 도입합니다. 탭이나 창을 닫은 뒤에도
에이전트가 작업을 계속하고, 다시 열면 실행 중인 같은 프로세스에 연결할 수
있습니다. Session Flow의 포크 복구를 개선하고 브라우저 요소에 대한 변경 요청
기능도 추가했습니다.

[English release notes](https://github.com/flowmux-ai/flowmux/blob/v0.15.0/docs/releases/0.15.0.md)

## Agent Host와 워크스페이스

- **New Agent**, **Resume in new tab**, Session Flow, `flowmux agent run`에서
  관리형 실행을 시작할 수 있습니다. 탭 연결을 해제한 에이전트는 **Agents**의
  **Background**에서 열고, Flowmux를 다시 시작하면 저장된 레이아웃의 탭에
  재연결할 수 있습니다.
- 실행 중인 에이전트가 있는 워크스페이스를 닫을 때 계속 실행, 종료, 취소 중에서
  선택할 수 있습니다. 워크스페이스의 마지막 창 분할이나 탭을 닫을 때도 같은
  확인 창이 표시됩니다.
- 실행 중인 에이전트와 Agent Host의 터미널을 다른 창이나 분할 영역으로 옮겨도
  같은 프로세스에 입력할 수 있습니다. 터미널 명령과 훅은 탭이 옮겨진 창을
  따라갑니다.
- 같은 Flowmux 인스턴스에서 분리한 창 사이로 탭을 끌어 옮길 수 있습니다.
  터미널 세션, 브라우저 페이지, 저장하지 않은 편집 내용도 유지됩니다.
- Agent Office에도 Agent Host 터미널에서 실행 중인 에이전트가 표시되며, 입력이
  필요한 상태 등은 Agents 목록과 일치합니다.
- Linux에서 관리형 실행을 시작하려면 systemd와 cgroup v2가 필요합니다. 다른
  프로토콜을 쓰는 빌드의 Agent Host는 기존 프로세스를 계속 실행할 수 있습니다.
  해당 빌드에서 다시 열거나, **Agents**의 **Stop other Host…**로 종료할 수
  있습니다. [Agent Host 안내](https://github.com/flowmux-ai/flowmux/blob/v0.15.0/docs/agent-sessions.md)

## Session Flow와 브라우저 변경 요청

- Session Flow에서 실행 중인 Claude Code 또는 Codex 포크에 다시 연결할 수
  있습니다. 열린 탭은 그 위치에서 복구하고, 백그라운드에 있으면 같은 프로세스를
  다시 엽니다. 훅 정보가 빠졌을 때도 실행 중인 프로세스의 근거를 통해 네이티브
  세션을 식별할 수 있습니다.
- Agent Sessions에서 Cline SR 기록을 볼 수 있고, Cline CLI 대화는
  네이티브 루트 세션 ID로 다시 열 수 있습니다.
- 브라우저에서 요소를 고르면 해당 영역의 스크린샷을 찍어 로컬 에이전트에
  편집 가능한 변경 요청을 보낼 수 있습니다. 취소하거나 전송에 실패하면 초안을
  보존합니다. [브라우저 변경 요청 안내](https://github.com/flowmux-ai/flowmux/blob/v0.15.0/docs/browser-workflow.md)
- macOS WebDriver는 페이지 이동이 반영된 뒤 문서를 읽습니다. 업데이트 중 오류가
  나면 연결한 디스크 이미지를 정리합니다.

## 다운로드

- Linux x86_64는 tarball과 Debian 패키지, macOS Apple Silicon은 DMG를
  제공합니다. 각 바이너리에는 SHA-256 체크섬이 포함되어 있습니다.
- macOS 프리뷰는 임시 서명(ad-hoc)을 사용하며 `/opt/homebrew` 아래에 Homebrew
  `gtk4`, `libadwaita`, `vte3` 런타임 라이브러리가 필요합니다. 설치 방법은
  DMG 내부 README에서 확인할 수 있습니다.
