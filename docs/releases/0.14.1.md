# Flowmux 0.14.1

Flowmux 0.14.1 updates bundled SQLite to address a memory disclosure advisory
and keeps background workspace automation from interrupting the workspace you
are using. These notes cover changes since v0.14.0.

[한국어 릴리스 노트](https://github.com/flowmux-ai/flowmux/blob/v0.14.1/docs/releases/0.14.1.ko.md)

## SQLite security update

- Upgrade `rusqlite` to 0.41.1 and `libsqlite3-sys` to 0.39.1, bundling
  **SQLite 3.54.1** instead of 3.46.0.
- Address [RUSTSEC-2026-0459 / CVE-2026-119375](https://rustsec.org/advisories/RUSTSEC-2026-0459.html).
  SQLite before 3.54.0 can expose uninitialized page-cache memory in query
  results when opening a crafted database together with a sibling WAL file
  whose page size differs. The attack requires opening attacker-controlled
  local files; exploitability in Flowmux has not been established.
- The update covers SQLite used by cookie import, native agent session history,
  Session Flow, and saved review drafts. No Flowmux database schema changes
  are introduced. Regression coverage includes reading live WAL session records
  while preserving the source database and WAL.

## Background work and agent teams

- Create workspaces without switching away using `workspace new --background`.
- Pane and tab commands in background workspaces preserve the visible workspace
  and its keyboard focus. New tabs use the pane remembered by `focus-pane`.
- Team workspaces default to the current agent. Delegation is reserved for
  useful independent work or explicit requests, and task-level failures are
  reported without automatically repeating the task.
- Improve regression fixtures for installed skills, shared GUI state, workspace
  focus and zoom, and agent storage restoration on macOS.
- Avoid closing an already dismissed process-termination dialog, including
  when reduced-motion settings make dismissal immediate.

## Updating and downloads

- Update the application and CLI together, then restart Flowmux when convenient
  to load the patched SQLite. Existing windows continue running the old build.
- Linux x86_64 downloads include a tarball and Debian package. macOS Apple
  Silicon downloads include a DMG. Each binary download has a `.sha256` file.
- The macOS preview requires Homebrew runtime libraries under `/opt/homebrew`.
  It is ad-hoc signed, not Developer ID signed or notarized. Intel macOS
  binaries are not provided.
