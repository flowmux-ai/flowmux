# Flowmux 0.15.0

Flowmux 0.15.0 introduces Agent Host on Linux. Agents can keep working after
you close a tab or window, and you can reconnect to the same running process
when you return. This release also improves Session Flow and adds browser
element feedback.

[한국어 릴리스 노트](https://github.com/flowmux-ai/flowmux/blob/v0.15.0/docs/releases/0.15.0.ko.md)

## Agent Host and workspaces

- Start a managed execution from **New Agent**, **Resume in new tab**, Session
  Flow, or `flowmux agent run`. Find detached executions under **Background**
  in **Agents**, or reopen Flowmux to reconnect the tabs in your saved layout.
- When closing a workspace with active agents, choose **Keep running**,
  **Terminate agent** or **Terminate agents**, or **Cancel**. The same prompt
  applies when closing the last pane or tab in the workspace.
- Move a live agent or hosted terminal between panes and windows while keeping
  its process and input. Terminal commands and hooks follow the window that
  now shows the tab.
- Drag tabs between windows detached from the same Flowmux instance.
  Terminal sessions, browser pages, and unsaved editor buffers stay live.
- Agent Office includes agents running in hosted terminals and uses the same
  attention status as the Agents list.
- Agent Host requires systemd and cgroup v2 for managed launches on Linux.
  If another Flowmux build uses a different Host protocol, its processes can
  keep running. Reopen them with the matching build, or use **Stop other Host…**
  in **Agents** to end them. [Agent Host guide](https://github.com/flowmux-ai/flowmux/blob/v0.15.0/docs/agent-sessions.md)

## Session Flow and browser feedback

- Reconnect to a running Claude Code or Codex fork from Session Flow. Restore
  the existing tab when it is open, or reopen the same process from
  **Background**. Flowmux can also recover a fork's session identity from
  native process evidence when hook data is missing.
- Agent Sessions discovers Cline SR history and resumes Cline CLI
  conversations using the native root session ID.
- Select an element in the browser, capture a cropped screenshot, and write
  an editable change request for a local agent. Flowmux preserves your draft
  if you cancel or delivery fails. [Browser feedback guide](https://github.com/flowmux-ai/flowmux/blob/v0.15.0/docs/browser-workflow.md)
- On macOS, wait for WebDriver navigation to commit before reading the page,
  and clean up attached disk images when an update fails.

## Downloads

- Linux x86_64 has a tarball and a Debian package. macOS Apple Silicon has a
  DMG. Each binary download comes with a SHA-256 checksum.
- The macOS preview uses ad-hoc signing and requires the Homebrew `gtk4`,
  `libadwaita`, and `vte3` runtime libraries under `/opt/homebrew`. See the
  README inside the DMG for installation guidance.
