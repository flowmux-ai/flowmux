# Flowmux 0.14.2

Flowmux 0.14.2는 브라우저 자동화와 페이지 읽기를 개선하고 탭 닫기 확인을
보강합니다. 이 문서는 v0.14.1 이후 변경 사항을 설명합니다.

[English release notes](https://github.com/flowmux-ai/flowmux/blob/v0.14.2/docs/releases/0.14.2.md)

## 브라우저 자동화와 페이지 읽기

- 모델용 고밀도 스냅샷과 읽기 전용 `read`, `links`, `grep`, `query`,
  `options` 명령을 추가합니다. 링크·선택자 조회는 프레임과 Shadow DOM도
  탐색하며, 고밀도 스냅샷에서 카드 번호와 인증 코드 등 민감한 값을 가립니다.
- `browser run`으로 최대 20개의 브라우저 명령을 일괄 실행합니다.
  뒤쪽 단계의 응답이 없어도 완료된 결과를 보존하고, 페이지 이동이나 대화상자 등
  새 관찰이 필요한 상황에서는 실행을 멈춥니다.
- 화면 높이 단위로 페이지나 내부 스크롤 영역을 이동하고, `eval` 스크립트를
  표준 입력으로 전달할 수 있습니다.
- 페이지 이동 시 교체된 문서를 기다리고, 빈 문서가 남는 경우를 포함해
  로딩 실패 원인을 더 명확히 알려줍니다.
- 클릭을 가리는 요소 안내, 모달 처리, 폼 참조 해석과 문서 교체 중 네이티브
  입력 완료 처리를 개선합니다.
- 브라우저를 열기 전에 호출한 Codex 세션을 확인합니다. 필요하면 `--pane`으로
  대상을 지정할 수 있으며, 세션 연결이 모호하면 다른 세션의 패널을 선택하지
  않고 실패를 알립니다.
- 스냅샷 루트마다 선택자 고유성을 한 번만 계산해 반복 작업을 줄입니다.

## 탭 닫기와 GTK 런타임 안내

- Alt+W에도 탭 닫기 확인 절차를 적용합니다.
- GTK 4.14.5 아이콘 캐시 수명 문제의 패치, 회귀 검사와 배포 안내를 제공합니다.
  이 패치는 GTK 런타임에 별도로 적용해야 하며, Flowmux 업데이트만으로
  활성화되지는 않습니다.

## 다운로드

- Linux x86_64는 tarball과 Debian 패키지, macOS Apple Silicon은 DMG를 제공합니다.
  각 바이너리 다운로드에는 `.sha256` 파일이 포함됩니다.
- macOS 프리뷰는 `/opt/homebrew`의 Homebrew 런타임 라이브러리가 필요합니다.
  임시 서명(ad-hoc) 상태이며 Developer ID 서명과 공증은 제공하지 않습니다.
  Intel macOS 바이너리는 제공하지 않습니다.
